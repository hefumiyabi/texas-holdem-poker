# 观战下一局与重新买入可读性设计

## 目标

筹码用完的真人选择“继续观看”后，牌桌不能停在结算画面；同时“重新买入”必须在手机和桌面端都清晰可读。

## 交互

- 玩家首次出局时保留“重新买入 / 继续观看 / 退出牌桌”。
- 选择继续观看后，将“继续观看”替换为“观看下一局”。
- 在只剩有筹码机器人的牌桌中，观战者点击“观看下一局”即可启动下一手，随后机器人按既有顺序完成牌局。
- 若仍有有筹码真人，继续沿用真人投票机制；观战者不能绕过其他真人直接开局。
- “重新买入”使用独立的高对比样式：实心金色背景、深色粗体、14px 字号，不使用模糊文字阴影。

## 边界

- 不增加自动无限牌局，避免无人观看时持续消耗单实例服务器资源。
- 不改变机器人决策、结算、座位顺序或买入限制。
- 中文显示“观看下一局”，英文显示“Watch next hand”。

## 验收

- 观战者在只剩机器人有筹码时能启动下一手。
- 有筹码真人仍必须完成原有投票，观战者不能单独启动。
- 重新买入按钮在移动端和桌面端具有明确的字号、字重和前景/背景对比。
